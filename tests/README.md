# tests/

Contrôles automatiques vérifiant que les écrans respectent le DSFR (classes, structure, accessibilité).

Commande : `npm run check -- <nom-d-ecran>` contrôle `screens/<nom>/` (index.html et etat-*.html) et écrit `screens/<nom>/rapport-tests.md` plus des captures dans `screens/<nom>/captures/`. Un chemin de dossier est aussi accepté (ex. `tests/fixtures/ecran-test`). Cinq contrôles : fidélité aux snippets officiels (structure, classes et attributs, avec tolérance sur les identifiants, les attributs d'état ARIA, les sous-composants imbriqués, le nombre et l'ordre des lignes de liste et des éléments d'un groupe de champs, le contenu libre des accordéons et des modales (hors titre), les éléments de texte sans classe DSFR à l'intérieur d'un paragraphe (lien, gras), et l'absence des parties que la doc déclare facultatives : description, détail, zone de tag et en-tête (pictogramme) de la tuile, titre de la mise en avant, icône du titre de la modale, ligne « Étape suivante » de l'indicateur d'étapes (absente sur la dernière étape) ; texte d'aide (description additionnelle) des champs et des choix ; le nom d'une icône est libre (« les icônes peuvent être changées ») ; un bouton DSFR peut être un lien `<a href>` quand il navigue ; le type d'une alerte (information, attention, erreur, succès) est interchangeable à taille égale, la doc le présentant comme combinable avec la taille ; les extraits sont lus sur la page d'exemple de chaque composant et sur ses sous-pages officielles, comme le lien « Haut de page » ou le lien de téléchargement, hors exemples dépréciés), classes inconnues et styles en ligne écrits dans le fichier (les variables CSS posées par le JavaScript du DSFR sont ignorées), contenus (faux-texte, libellés génériques), accessibilité axe et captures aux largeurs 320 à 1248 px, documentation lue (chaque composant présent dans l'écran doit avoir dans `conception.md` une ligne « Doc lue : reference/doc/composants/<nom-technique>.md », la copie de la doc officielle produite par `npm run doc`). La commande échoue (code 1) dès qu'il y a un écart au premier, au deuxième ou au cinquième contrôle.
