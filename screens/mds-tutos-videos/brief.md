# Brief : Les tutos vidéos, traduits en DSFR

## 1. Le service et son public
mesdroitssociaux.gouv.fr. Page des six tutoriels vidéo du portail, avant connexion. Contenus relevés sur https://www.mesdroitssociaux.gouv.fr/accueil/les-tutos-videos le 30/09/2026.

## 2. La user story
En tant qu'usager peu à l'aise avec le numérique, je veux regarder ou lire un tutoriel, afin de comprendre comment utiliser le portail.

## 3. Le point de départ
Même squelette que mds-accueil. Pas de template maison.

## 4. Les contenus réels
En-tête, navigation, pied de page : identiques à mds-accueil. Fil d'Ariane : Accueil > Les tutos vidéos.
Titre (h1) : LES TUTOS VIDÉOS. Chapô : Découvrez tous les services proposés sur mesdroitssociaux.gouv.fr à l'aide de petites vidéos explicatives.
Six tutoriels : La page d'accueil ; La connexion ; Vos droits ; Votre simulateur ; Vos ressources ; Vos signalements. Pour chacun : texte Pour voir cette vidéo, vous devez autoriser les cookies « Vidéo » Dailymotion. ; bouton secondaire Gérer les cookies ; lien Voir la transcription textuelle du tuto vidéo « <nom> ».
Lien externe : Découvrir notre page Dailymotion. Lien de retour : Revenir à l'accueil.

## 5. Les états et le parcours
Un seul état. La transcription de « La connexion » mène à la page type mds-transcription ; les autres transcriptions et la page Dailymotion sont provisoires (#).

## 6. Les contraintes
Niveau RGAA AA, mobile d'abord (une colonne sur mobile, trois sur bureau), aucune image, aucun style hors DSFR, un seul h1, un h3 par tutoriel.

## 7. Les critères d'acceptation
- Chaque vidéo est le placeholder de consentement officiel avec un bouton secondaire ; chaque transcription est un lien DSFR.
- Textes mot pour mot ; aucune classe hors DSFR, aucun style en ligne, aucun faux-texte.
