# Brief : Plan du site, traduit en DSFR

## 1. Le service et son public
mesdroitssociaux.gouv.fr. Plan du site, avant connexion. Contenus relevés sur https://www.mesdroitssociaux.gouv.fr/dd1pnds-ria/#destination/planSiteFooter le 30/09/2026.

## 2. La user story
En tant qu'usager, je veux voir toutes les pages du site en une liste, afin d'y accéder directement.

## 3. Le point de départ
Même squelette que mds-accueil, corps de texte sur 8 colonnes. Pas de template maison.

## 4. Les contenus réels
En-tête, navigation, pied de page : identiques à mds-accueil. Fil d'Ariane : Accueil > Plan du site. Titre (h1) : Plan du site.
Liste hiérarchique de liens, dans l'ordre du site : Accueil ; Vos services (Vos droits, Vos ressources, Vos simulateurs, Votre activité professionnelle, Vos signalements, Vos rappels) ; Vos événements de vie (Vous recherchez un emploi, Vous attendez un enfant, Vous adoptez un enfant, Vous avez besoin de faire garder vos enfants, Vous devez faire face à un décès, Autonomie et grand âge, Votre enfant est en situation de handicap, Vous êtes en situation de handicap) ; Aide d'urgence aux victimes de violences conjugales ; Les tutos vidéos ; Foire aux questions ; Contact ; Qui sommes nous? ; Mentions légales ; Gérer les cookies ; Accessibilité ; Plan du site.

## 5. Les états et le parcours
Un seul état. Les entrées qui existent dans le prototype y mènent (Accueil, Vos événements de vie, Vous attendez un enfant, Vous devez faire face à un décès, Aide d'urgence aux victimes de violences conjugales, Les tutos vidéos, Foire aux questions, Contact, Qui sommes nous?, Mentions légales, Accessibilité, Plan du site) ; les autres sont provisoires (#).

## 6. Les contraintes
Niveau RGAA AA, mobile d'abord, aucune image, aucun style hors DSFR, un seul h1.

## 7. Les critères d'acceptation
- Les liens sont dans des listes imbriquées, avec un libellé explicite chacun.
- Libellés mot pour mot ; aucune classe hors DSFR, aucun style en ligne, aucun faux-texte.
